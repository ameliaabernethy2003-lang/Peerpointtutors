# Data Entry Template

Use this template to record exact values from Item 8 of SEC 10-K filings.
All values should be in THOUSANDS (as reported in SEC filings).

## Instructions
1. Open each 10-K filing using the links from `node scripts/get-filing-links.js`
2. Navigate to Item 8 → Financial Statements and Supplementary Data
3. Copy exact values from the financial statements
4. Fill in this template
5. Share the completed template and I'll update the data files
