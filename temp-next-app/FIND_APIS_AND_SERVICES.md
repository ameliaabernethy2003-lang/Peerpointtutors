# How to Find "APIs & Services" in Google Cloud Console

## 🔍 Method 1: Left Sidebar (Most Common)

1. **Look at the LEFT SIDEBAR** of the page
2. You'll see a menu with options like:
   - Home
   - APIs & Services ← **CLICK THIS ONE**
   - IAM & Admin
   - Billing
   - etc.

3. **Click "APIs & Services"** - it's usually near the top of the sidebar

4. If you don't see it, look for a **hamburger menu (☰)** in the top left corner and click it to expand the menu

---

## 🔍 Method 2: Top Navigation Bar

1. **Look at the TOP BAR** of the page
2. You might see a search bar that says "Search products and resources"
3. **Type "APIs"** in the search bar
4. Click on "APIs & Services" from the dropdown

---

## 🔍 Method 3: Direct URL

If you can't find it, you can go directly to:
**https://console.cloud.google.com/apis/dashboard**

---

## 📍 What You'll See After Clicking

Once you click "APIs & Services", you'll see options like:
- **Dashboard** - Overview of APIs
- **Library** ← **CLICK THIS** (to enable Google Calendar API)
- **Credentials** ← **CLICK THIS** (to create service account)

---

## 🆘 Still Can't Find It?

**Try this:**
1. Make sure you're signed in to Google Cloud Console
2. Make sure you have a project selected (check the project dropdown at the top)
3. Look for the **☰ (hamburger menu)** in the top left - click it to expand the sidebar
4. Scroll down the sidebar - "APIs & Services" should be there

**Visual Guide:**
```
Google Cloud Console
├── ☰ Menu (top left)
├── Project Dropdown (top)
└── Left Sidebar:
    ├── Home
    ├── APIs & Services ← HERE!
    │   ├── Dashboard
    │   ├── Library ← Enable API here
    │   └── Credentials ← Create service account here
    ├── IAM & Admin
    └── ...
```

---

## 💡 Quick Tip

If the sidebar is collapsed (you only see icons), click the **☰ menu** to expand it and see full text labels.
